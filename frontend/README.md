# frontend/

Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 + shadcn/ui. Talks to the FastAPI backend.

| Path | What lives here |
| --- | --- |
| `app/` | Routes. `/` new chat, `/chat/[id]` a conversation, `/knowledge`, `/graph`, `/analytics`, `/settings`; `api/health` for Docker |
| `components/` | App components, one per file (sidebar, nav, conversation list, theme toggle, page header/placeholder) |
| `components/chat/` | Chat UI: `chat-view` (page), `message-list`, `message-bubble`, `composer`, `model-switcher`, `error-banner`, `message-meta`, `empty-state` |
| `components/ui/` | shadcn/ui components, copied in by the CLI. Ours to edit (two are modified, see docs/decisions.md) |
| `lib/events.ts` | TypeScript mirror of `backend/core/events.py`. **Must match exactly.** |
| `lib/use-chat-stream.ts` | Sends a message and reads the SSE stream (fetch + ReadableStream), with Stop support |
| `lib/api.ts` | Typed client for the JSON endpoints |

Run outside Docker: `npm install && npm run dev` → http://localhost:3000 (backend must be on :8000).
After changing dependencies in Docker: `docker compose up -d --build -V frontend` (`-V` renews `node_modules`).

`AGENTS.md` is generated by Next.js itself (pointers for AI coding agents) and is re-created by `next dev`.
