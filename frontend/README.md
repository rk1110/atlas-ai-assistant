# frontend/

Next.js 16 (App Router) + TypeScript + Tailwind CSS. shadcn/ui, the app shell and chat UI arrive in
Phase 1, steps 6–7.

| Path | What lives here |
| --- | --- |
| `app/` | Pages (routes): `/` chat, `/knowledge`, `/graph`, `/analytics`, `/settings`; `api/health` for Docker |
| `components/` | UI components, one per file (step 6+) |
| `lib/events.ts` | TypeScript mirror of the backend `StreamEvent` types. **Must match `backend/core/events.py` exactly.** |

Run outside Docker: `npm install && npm run dev` → http://localhost:3000

`AGENTS.md` is generated by Next.js itself (pointers for AI coding agents) and is re-created by `next dev`.
